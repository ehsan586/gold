# اجرای یک‌کلیکی ASTRA با MT4

## هدف
بعد از انجام Setup اولیه، روند روزانه فقط این است:

1. MT4 را باز کن.
2. Docker را در صورت نیاز باز کن (لانچر محلی ASTRA برای اجرا به Docker وابسته نیست).
3. روی `run.bat` دوبار کلیک کن.
4. داشبورد به‌صورت خودکار باز می‌شود.
5. برای توقف روی `stop.bat` دوبار کلیک کن.

## Setup اولیه MT4 — فقط یک بار
`run.bat` با یک bootstrap پایتونی مستقل اجرا می‌شود، فایل `ASTRAFeedEA.mq4` را در پوشه‌های استاندارد MT4 پیدا کرده و کپی می‌کند؛ اما Compile و اتصال EA به یک Chart مشخص، قابلیت داخلی MT4 است و باید یک‌بار داخل MetaEditor/MT4 انجام شود.

اگر Feed هنوز وجود نداشته باشد، فقط یک بار:

- MT4 را باز کن.
- نمودار XAUUSD را باز کن.
- از Navigator > Expert Advisors، `ASTRAFeedEA` را روی نمودار بکش.
- EA فقط داده بازار را می‌خواند و هیچ سفارشی ارسال/ویرایش/بسته نمی‌کند.
- صبر کن `ASTRA_MT4_FEED.json` ساخته شود.

بعد از این مرحله، در اجراهای بعدی Attach کردن EA لازم نیست، به شرطی که MT4 پروفایل/چارت را نگه دارد و EA روی چارت فعال بماند.

## نکته مهم
هیچ launcher ویندوزی نمی‌تواند بدون اتکا به automation شکننده، تضمین کند که یک Expert Advisor به یک Chart مشخص در MT4 متصل شده است. بنابراین Setup بالا عمداً فقط یک بار انجام می‌شود و `run.bat` در هر اجرا Feed را Health-check می‌کند.

## حالت اجرا
نسخه فعلی **SIMULATION** است. Feed از MT4 فقط Read-Only است و موتور اجرای سفارش واقعی در این build فعال نیست.

اگر Feed قطع شود، داده قدیمی شود، API بالا نیاید یا سلامت سیستم تأیید نشود، `run.bat` اجرای سالم را تأیید نمی‌کند.
