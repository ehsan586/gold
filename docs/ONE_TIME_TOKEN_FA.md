# توکن شخصی یک‌بار مصرف ASTRA

برای تعیین توکن خودتان: `CREATE_API_TOKEN.bat` را فقط یک بار اجرا کنید.
توکن در `ASTRA_API_TOKEN.txt` ذخیره می‌شود و `bootstrap.py` از همان فایل برای مقدار `GOLDBOT_API_TOKEN` استفاده می‌کند.
مرورگر نیز توکن واردشده را در localStorage همان دستگاه نگه می‌دارد.

این توکن API پولی هوش مصنوعی نیست و کاملاً محلی است. برای اجرای اصلی لازم نیست `OPENAI_API_KEY` یا `ANTHROPIC_API_KEY` تنظیم شود.
